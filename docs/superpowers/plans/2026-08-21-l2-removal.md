# 全局移除 L2 角色分层 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 从 easy_game 全代码库彻底移除 L2 角色分层，收敛为 L1 + actor 两层模型，源码（非测试、非注释）不再出现 `L2` / `l2_profile`。

**Architecture:** 单分支 chained off `main`，按依赖自底向上重构：类型核心 → 容量/roster → 创建流程 → 调度/运行时 → 持久化 → 死代码删除 → 测试/验收。L2 作为独立数据结构完全删除；原次要角色并入 L1（玩家绑定 + `l1_profile`），"剧情占比更少"交给 Director 两层调度与剧情自然表达，**不**在 L1 内部新增主角/次要机制。不写任何为遗留 L2 数据保留的兼容/迁移分支。

**Tech Stack:** Python 3, SQLAlchemy (Persistence), unittest 风格测试经 pytest 9.1.1 运行。

**用户已确认的关键裁决（覆盖 spec 中的开放项）：**
- `store_snapshot._resolve_story_layer`：**不写** L2→L1 字面量分支。L2 数据结构已彻底不存在，不会再有 `story_layer="L2"`/`agent_type="L2"` 的 profile，函数保持只认 `player/actor/L1`（现状即如此，无需改动）。
- `promote_character_profile_to_l1`：全代码库仅测试引用（`tests/test_agent_profile_layers.py:20,288`），无生产调用方 → **连函数带测试一起删除**。
- `web_session.py:124`（复制 `l2_profile`）、`PlayerWriter/PlayerWriterAgent.py:47`（prompt 提 L2 容量）：spec 未列，本计划纳入——直接删行/改文案，不做兼容搬运。
- 次要角色不在代码里保留软性优先级；Director 三层排序收敛为两层。

**测试运行命令（全计划统一）：** 在 `easy_game/` 目录下运行 `python -m pytest <path> -v`。

**注意：** 本项目受 GitNexus 索引约束（见 `easy_game/CLAUDE.md`）。编辑任一 symbol 前先跑 `impact({target, direction:"upstream"})`，提交前跑 `detect_changes({scope:"compare", base_ref:"main"})`。每个任务提交前执行这两步。
