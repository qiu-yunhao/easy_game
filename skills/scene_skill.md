# Scene Skill

## 模块描述
提供当前场景、登场角色、当前章节目标与运行时约束的只读查询。
当编剧、导演或角色创建 Agent 需要确认“现在场上是谁、地点是什么、当前戏剧压力和场景计划是什么”时，应使用此技能。

## 可用 Tools

### 1. query_scene_context
- 功能：查询当前场景上下文，包括地点、时间、登场角色、场景计划、导演简报与运行时限制。
- 典型用途：
  - 判断当前场景适不适合引入新角色
  - 判断场上已有角色是否足够支撑下一拍
  - 判断当前场景是否允许打断、转场或继续升压

## 使用约束
- 这是只读工具，不修改任何状态。
- 如需决定是否新增角色，通常应与 `character_roster_skill` 结合使用。
- 如需理解最近的冲突走势或未解线索，通常应与 `memory_skill` 结合使用。
