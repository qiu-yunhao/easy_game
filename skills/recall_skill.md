# Recall Skill

## 模块描述
长期回忆检索：让玩家用自然语言追问「以前经历过什么」，从**已结束的幕**里检索相关的历史片段。

## 触发词
回忆、之前、经历、记得、曾经、以前、过去、recall、remember、past

## 可用 Tools

### query_recall
- 功能：根据自然语言 `query` 检索玩家过往已结束幕的相关历史片段。
- 参数：
  - `query`（必填）：玩家想回忆的内容描述。
  - `top_k`（可选）：最多返回的片段数，默认 10。
- 返回：`results` 列表，每项含 `scene_id` / `chapter_id` / `text` / `score`。

## 触发事件
仅当玩家**主动**用自然语言询问过往经历时触发，例如「我之前经历过什么」「还记得那个人吗」「以前发生了什么」。不要在玩家描述当前动作或推进剧情时触发。

## 使用场景 / 边界
- **只读**：不修改任何游戏状态，不推进剧情。
- **仅覆盖已结束的幕**：进行中的当前幕不在向量库里，查不到属正常。
- **多租户隔离**：只检索当前激活存档（user/player）自己的回忆，绝不跨玩家。
- **结束时机**：单次查询即返回即结束，无后续状态。

## 边界情况
- 回忆服务未注入（未启用）→ 返回「回忆功能未启用。」，不报错。
- `query` 为空 → 校验失败，提示需提供回忆内容。
- 无激活存档上下文（user/player 缺失）→ 失败，提示没有激活存档。
- 检索无命中 → 返回成功 + 「没有找到相关的回忆。」，`results` 为空，而非报错。
